# Horror Robot Survival Game

## Описание
Хоррор-игра на выживание с боевой системой против ИИ-роботов и монстров.

## Возможности
- **Два босса**: Босс ИИ (в здании) и Босс Монстр (в пещерах)
- **Враги**: Роботы ИИ и монстры с разным поведением
- **Оружие**: Дробовик (60 патронов) и огнемет (для нахождения)
- **Инвентарь**: Еда, вода, фонарик, дневник с кодами
- **Коды серверов**: Найти коды на роботах для отключения
- **Спасение**: Освободить рабов, победив обоих боссов

## Инструкции по запуску
1. Установите Godot Engine 4.0+
2. Откройте проект в Godot
3. Нажмите F5 для запуска
4. Для Android: Экспортируйте как APK через меню Export

## Управление
- WASD - движение
- Мышь - камера
- Левый клик - стрелять
- Shift - бег
- ESC - выход
